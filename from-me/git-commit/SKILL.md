---
name: git-commit
description: Create a clean conventional Git commit for the current changes.
---

Create a Git commit:

- Commit on the current branch; do not create a new branch.
- Use the existing Git configuration.
- `type(scope): subject`
- Focus on functional and behavioral changes.
- Do not describe implementation details.
- Use imperative verbs.
- Run git commit after preparing the commit message.
