# Question-Driven Writing

Use this skill for framework-first, question-driven writing.

Do not start with a full draft unless the user explicitly asks for direct drafting.

## Method

First output a simple two-level Markdown list:

- Level 1: framework items.
- Level 2: many guiding questions under each framework item.

Framework items do not need to be questions. They may be themes, angles, claims, sections, or other useful labels. The framework organizes the writing; the questions develop the thinking.

Prefer questions that reveal tension, ambiguity, problems, gray areas, missing reasoning, possible evidence, counterarguments, or the "so what" of the topic. Avoid making the question list mostly factual or descriptive.

Treat the framework as provisional. After the user responds, revise the framework if their answers reveal a better structure.

After giving the framework, ask the user what to keep, remove, combine, split, rename, or emphasize.

Then continue through the chosen framework with deeper questions. When enough material exists, turn the answers into claims, paragraph plans, draft paragraphs, or a complete draft.

## Format

```md
- Framework item
  - Guiding question
  - Guiding question
  - Guiding question

- Framework item
  - Guiding question
  - Guiding question
  - Guiding question
```

Keep the format simple. Avoid long templates, tables, and over-detailed examples unless the user asks for them.
