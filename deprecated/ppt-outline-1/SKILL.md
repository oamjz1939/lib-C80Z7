# PPT 大纲生成器

将文章内容转换为 PPT 构思大纲。**先询问用户需要几页**，然后生成相应的大纲。

## 使用方式

**正确的顺序**：
1. 用户表达想要构思 PPT 的意图（如 "帮我构思 PPT"）
2. **立即询问用户需要几页 PPT**：使用 question 工具
3. 用户回答后，请用户粘贴文章内容
4. 根据用户指定的页数，生成相应的大纲

## 询问页数

使用 question 工具询问用户（必须先询问，再生成大纲）：

```
您希望这个 PPT 有几页？
- 5 页：简洁版，适合短时间演讲
- 8-10 页：标准版，内容更完整
- 15+ 页：详细版，包含更多背景和案例
```

选项格式示例：
```json
{
  "question": "您希望这个 PPT 有几页？",
  "header": "PPT 页数",
  "options": [
    {"label": "5 页", "description": "简洁版，适合短时间演讲"},
    {"label": "8-10 页", "description": "标准版，内容更完整"},
    {"label": "15+ 页", "description": "详细版，包含更多背景和案例"}
  ]
}
```

## 输出格式

每页包含：
- **标题**：幻灯片标题
- **内容**：核心要点（2-4 条）
- **图片建议**：推荐的视觉元素类型
- **备注**：演讲备注（可选）

## 动态页数结构

根据用户选择的页数，动态调整大纲结构：

| 页数 | 内容 |
|------|------|
| 1 | 标题页 - 主题 + 副标题 |
| 2 | 背景/现状 - 传统结构 + 变化驱动力 |
| 3 | 核心内容 - 主要论点/新概念 |
| ... | 可扩展页面 |
| 最后 | 总结 - 核心观点 + 行动建议 |

## 分析步骤

### 1. 结构识别
- 识别文章的核心问题/主题
- 提取 3 个主要论点或新概念
- 识别对比关系（传统 vs 新、问题 vs 解决方案）
- 识别流程或演变过程

### 2. 信息压缩
- 将长文压缩为关键要点
- 保留专业术语和核心数据
- 识别可视觉化的概念

### 3. 图片类型映射

| 概念类型 | 推荐图片 |
|----------|----------|
| 层级结构 | 金字塔图、层级图 |
| 演变过程 | 时间线、流程图 |
| 对比关系 | 并排对比图、左右分栏 |
| 并列概念 | 三列并排、图标列表 |
| 循环流程 | 循环流程图、Mermaid |
| 数据/指标 | 图表、饼图、柱状图 |

- **图片建议**：协作、展望类插画
